## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

Amazon Web Services (AWS) offers the broadest range of services with over 200 fully-featured services, including compute, storage, databases, analytics, machine learning, and IoT. Its long history and market leadership have allowed it to build the most extensive portfolio of cloud services.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure offers the best integration with Microsoft technologies, providing native support for Windows Server, Active Directory, Microsoft 365, and other Microsoft products. This makes Azure the natural choice for organizations already invested in the Microsoft ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform is strongest in Artificial Intelligence and Kubernetes, being the creator of TensorFlow and Kubernetes. GCP offers advanced AI/ML services through Vertex AI and is known as the home of Kubernetes with its Google Kubernetes Engine (GKE).

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform because of its strong focus on data analytics, machine learning, and container orchestration. As a technology enthusiast interested in AI and modern application development, GCP's innovative tools and developer-friendly approach align well with my interests. Additionally, GCP's clean UI and powerful data services like BigQuery make it attractive for data-intensive projects.
